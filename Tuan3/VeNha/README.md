# Bài tập CSS cơ bản, Tuần 3 (Phát triển ứng dụng WEB/TMĐT)

Mở file `Tuan3/VeNha/index.html` để xem các liên kết bài tập.

- **Bài 1:** `BaiTap1.docx`: minh chứng người học đã cung cấp, giữ nguyên.
- **Bài 2:** `BaiTap2.html`, phần a đến e. Hiệu ứng BIT-UEH làm bằng CSS `text-shadow`.
- **Bài 3:** lựa chọn phương án b: làm Bài 4, 5, 6, 7.
- **Bài 4:** `BaiTap4.html`: 4 ô menu cyan, liên kết xanh gạch chân.
- **Bài 5:** `BaiTap5.html`: Shared Hosting, logo UEH/BIT lưu local.
- **Bài 6:** `BaiTap6.html`: My Portfolio, ảnh placeholder lưu local.
- **Bài 7:** `BaiTap7.html`: bố cục `header/nav/main/footer` theo đúng thứ tự HTML trong đề.
- **Bài 8:** `BaiTap8.html`: từ `css1.zip`, dùng đủ bốn ảnh gốc trong `assets/heroes/`.
- **Bài 9:** `BaiTap9.html`: Font Awesome 6.7.2, CSS và font lưu local tại `assets/fontawesome/`.
- **Bài 10:** `index.html`: liên kết nội bộ tới các bài, avatar mèo người dùng cung cấp, Facebook cá nhân, GitHub cá nhân và repository bài tập.

## Nộp GitHub

Không tải lên file ZIP. Giải nén, sau đó đưa nguyên thư mục `Tuan3/VeNha` vào repository GitHub và giữ nguyên `assets/`.

Ví dụ tại thư mục gốc repository:

```bash
git add Tuan3/VeNha
git commit -m "Hoan thanh bai tap CSS co ban tuan 3"
git push origin main
```

Lưu ý: GitHub phải có quyền ghi và local repo đã cấu hình remote phù hợp trước khi chạy lệnh.

## Tài nguyên

- Logo UEH/BIT: lấy từ hình mẫu trong PDF mà người học cung cấp, không phải hotlink.
- Các ảnh trong Bài 8: trích nguyên vẹn từ file css1.zip của người học.
- Font Awesome Free 6.7.2: theo `assets/fontawesome/LICENSE.txt`.
- Ảnh avatar `avatar-cat.jpg`: ảnh mèo do người học cung cấp, lưu local; không sử dụng ảnh giả.
